
# MephistDataKit

`MephistDataKit` - набор утилит для удалённого доступа и анализа базы данных разрядов плазмы сферического токамака МИФИСТ (MEPhIST). Он может работать через сеть Интернет с использованием персональных реквизитов входа на портал [**tokamak.mephi.ru**](https://tokamak.mephi.ru).

## 🎯 Описание проекта

MephistDataKit — это Python-пакет для работы с HDF5/NeXuS файлами токамака МИФИСТ. Он предоставляет:

1. **Удаленный доступ к данным**: Клиент на базе **[requests](https://pypi.org/project/requests/)** для взаимодействия с REST API хранилища данных токамака через персональные токены доступа, генерируемые на портале [**tokamak.mephi.ru**](https://tokamak.mephi.ru)
2. **Автоматическое кэширование**: При первом обращении к файлу разряда он сохраняется локально для минимизации нагрузки на сервер и ускорения обработки данных. Объем кэша может быть настроен, также кэширование может быть вовсе выключено.
3. **Обработка данных**: Библиотека регулярно актуализируемых методов для анализа сигналов с токамака (ток плазмы, интерферометрия и др.), основанная на наработках сотрудников лаборатории.
4. **Расширяемость**: Возможность модернизации и добавления новых методов обработки и примеров студентами и аспирантами в единую экосистему с использованием инструментария Git. 

У репозитория фактически две главные цели: 
* Обеспечить прямой удалённый доступ к данным множества пользователей с возможностью задействования локальных вычислительных ресурсов для обработки. Во-первых, чтобы снизить нагрузку на веб сервисы, а во-вторых - для реализации возможности работы с большими данными, что в используемом сервере JupyterLab сложно реализуемо.
* Стать основным источником актуальных методов обработки данных. Так, например, при изменении коэффициентов для расчёта тока плазмы, автор может сделать pull request. При этом, во-первых, Git обеспечит сохранение истории изменений, а во-вторых, позволит реализовать оперативную дистрибуцию обновлений среди пользователей и автоматическое внедрение (CI/CD) изменений в скрипты сбора и обработки данных (упаковщики HDF5, генераторы графиков на веб портале и т.д.).

### 2. Настройка конфигурации

Копируете файл `config_example.yaml` и меняете название на `config.yaml`. Не используйте файл  `config_example.yaml`, так как он индексируется в Git, что может скомпрометировать ваш персональный токен доступа. Также по умолчанию клиент ищет конфигурацию в файле с названием `config.yaml` в корневой директории проекта. Вставляете токен доступа, полученный по инструкции из раздела `🔑 Получение доступа к API` (представлена ниже), в поле `api_token`. Для начала остальные настройки можно оставить по умолчанию.

Также при работе с большим числом импульсов, когда в терминале часто могут возникать оповещения об отсутствии той или иной диагностики в базе данных, может быть удобным выключить часть оповещений с помощью настроек `show_progress` и  `console_level`. При варианте `ERROR` выводятся только ошибки, при варианте `WARNING` - ошибки и предупреждения, при варианте `INFO` - все сообщения (имеет смысл для дебага). При этом настройка `show_progress` работает независимо.

```yaml
# Конфигурация Mephist API Client

# Настройки подключения
server:
  base_url: "https://tokamak.mephi.ru/"
  base_path: "/orders/shots-api/"
  verify_ssl: true                  # для самоподписанных сертификатов

# Аутентификация ПОМЕНЯЙТЕ ТОКЕН НА СВОЙ
auth:
  api_token: "your_personal_token"

# Настройки загрузки данных
download:
  chunk_size: 8192                  # Размер чанка для скачивания
  timeout: 5                        # Таймаут запроса (секунды)
  retry_attempts: 3                 # Количество попыток при ошибке
  show_progress: true               # Включить/выключить прогресс-бар

# Настройки кэширования данных
cache:
  use_cache: true                   # Использовать кэш по умолчанию (в противном случае каждый раз будет скачиваться с сервера)
  cache_dir: "./.cache"              # директория для хранения кэша (Создаётся автоматически)
  cache_max: "3 GB"                 # Макксимальный размер кэша в формате "500 MB", "1GB", "100KB" и "0" для отключения ограничения

logging:
  console_level: "INFO"             # Уровень вывода сообщений в консоль: ERROR, WARNING, INFO
  verbose_stats: true               # выводить подробную информацию для статистики сервера
```

>**Важно:** Замените `your_personal_token` на токен, полученный на портале токамака.


### 3. Первый запуск

1. **Откройте проект** в VS Code: `File → Open Folder → выберите MephistDataKit`
2. **Выберите интерпретатор**:
	- Нажмите `Ctrl+Shift+P` (или `Cmd+Shift+P` на macOS)
	- Выберите `Python: Select Interpreter`
	- Выберите `mephistdatakit` из вашего проекта (если устанавливали зависимости в виртуальной серед venv) или стандартный Python, если через pip.
3. Скопируйте файлы из директории `examples` в директорию `workdir`
4. Откройте любой скопированный пример из workdir
5. Запустите скрипт напрямую из VS Code правой кнопкой → "Run Python File", либо кнопкой в форме повёрнутого треугольника в правом верхнем углу.
6. Вы успешны

#### 2. Получаете экземпляр пакета MephistDataKit. Для этого 

#### 2.1 Открываете терминал (Terminal/PowerShell) в любой директории, куда хотите установить пакет.  Для этого нажимаете в желаемой директории правую кнопку мыши  -> `Открыть в терминале` (либо `git bash here`, либо нажать ПКМ над левым верхним углом файлового менеджера и нажать `Открыть в Powershell`).

## 🔑 Получение доступа к API

Для работы с данными токамака через сеть Интернет необходимо получить персональный токен доступа, представляющий собой последовательность из 60 символов. Для этого:

1. **Запросите регистрационную ссылку** у сотрудников лаборатории или по почте `tokamak@mephi.ru` для создания реквизитов входа на портал 
2. **Войдите на портал** [**tokamak.mephi.ru**](https://tokamak.mephi.ru) с использованием полученных логина/пароля
3. После успешной авторизации **перейдите на [страницу личных настроек](https://tokamak.mephi.ru:8443/if/user/#/settings)**.
4. **Откройте раздел** `Токены и приложения`
5. **Нажмите кнопку** `Создать токен` и задайте ему произвольное имя (без  кириллицы!)
6. В появившейся вкладке `Действия` нажмите  `Копировать токен` и вставьте его в файл `config.yaml`, который вы должны предварительно создать сами на основе шаблона (см. пример ниже или в файле `config_example.yaml`).
7. Не сообщайте никому ваш токен и не храните его на общедоступных ресурсах. При компроментации удалите токен на **[странице личных настроек](https://tokamak.mephi.ru:8443/if/user/#/settings)** и создайте новый.

Обратите внимание, что токены пользователей со статусом "Администратор" не принимаются!

## 📦 Основные модули

### mephistdatakit.client

Модуль для взаимодействия с API токамака МИФИСТ. Основной класс — `Client`. Предоставляет методы для аутентификации, получения списка импульсов, скачивания данных и работы с кэшем.

### mephistdatakit.shot

Модуль для обработки и анализа данных токамака. Основной класс — `Shot`. Содержит функции для:

- Расчет тока плазмы из данных Роговского зонда
- Обработка интерферометрических данных для измерения электронной плотности
- Работа с HDF5 файлами токамака МИФИСТ
- и многое другое


## 📝 Примеры использования

### Пример 1: Проверка соединения с сервером и валидности токена

```python
import mephistdatakit as mdk

# Создаем объект клиентского приложения с токеном, указанным в файле config.yaml
client = mdk.Client()

# В принципе вы можете задать имя файла конфига, но имейте в виду, что его не будет в .gitignore
client = mdk.Client("my_config.yaml")

# Проверяем соединение с сервером (Необязательно)
client.test_connection()

# Проверяем аутентификацию (Необязательно, она повторяется при каждом запросе файла)
client.authenticate()

# Получаем list со списком импульсов в int листе
shots_list = client.get_shots_list()
print(shots_list)
```

### Пример 2: Загрузка данных с сервера


```python
import mephistdatakit as mdk

client = mdk.Client()

for shot_id in shots_list[shots_list.index(3063):shots_list.index(3063)+4]:
    hdf5_file = client.get_shot(shot_id)
    shot = mdk.Shot(hdf5_file)
    
    try:
        time, plasma_current = shot.get_plasma_current()
        time, plasma_density = shot.get_plasma_density()
        print(f"СТАТИСТИКА: импульс {shot_id}   {shot.get_gas()} {shot.get_pressure():.2e} mBar  {max(plasma_current):.2f} kA {max(plasma_density):.1e} m^2")
    except:
        pass
```

### Пример 3: Работа с кэшем

```python
import mephistdatakit as mdk

# Создаем объект клиентского приложения с токеном, указанным в файле config.yaml
client = mdk.Client()

cache_info = client.cache_info()
print(f"Файлов в кэше: {cache_info['files_count']}")
print(f"Размер кэша: {cache_info['total_size_mb']:.2f} MB")

client.cache_management("cleanup")

# реально ничего не удалилось, так как объём кэша меньше параметра cache_max в config.yaml

cache_info = client.cache_info()
print(f"Файлов в кэше: {cache_info['files_count']}")
print(f"Размер кэша: {cache_info['total_size_mb']:.2f} MB")

client.cache_management("clear")
# Вот теперь кэш пустой
cache_info = client.cache_info()
print(f"Файлов в кэше: {cache_info['files_count']}")
print(f"Размер кэша: {cache_info['total_size_mb']:.2f} MB")

```
