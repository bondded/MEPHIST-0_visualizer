# Внесение изменений в основной репозиторий

По умолчанию прямое внесение изменений в основную ветку main репозитория через git push доступна лишь ограниченному кругу пользователей (мейнтейнеров).

В общем случае для добавления нового коммита обычному пользователю нужно сделать следующее:


### 1. Сделать ответвление репозитория (fork) 
Для этого на сайте **[tokamak.mephi.ru/git](https://tokamak.mephi.ru/git/mephist0/MephistDataKit)** для интересующего репозитория нажать кнопку "Ответвление" и Создать ответвление. Рекомендуется изменить имя создаваемого репозитория, чтобы не путать других пользователей, например: `fork-MephistDataKit-by-{Username}`

### 2. Склонировать созданный репозиторий (clone)

Для этого на персональном компьютере выполнить команду 

`git clone https://tokamak.mephi.ru/git/{Username}/fork-of-MephistDataKit-by-{Username}.git`

Подробнее описано в файле [README](../README.md).

### 3. Внести изменения в репозиторий

Запустить код по инструкции из [README](../README.md). Внести желаемые изменения в репозиторий, выполнить команды:

```bash
git add -u
git add {добавленные вами файлы, которые вы хотите внести в репозиторий}
git commit -m "{Комментарий, который будет виден всем пользователям}"
git push
```

При составлении комментария рекомендуется следовать [Cоглашению о коммитах](https://github.com/qoomon/git-conventional-commits)

### 4.Создать запрос на слияние (pull request)

Перед созданием запроса убедитесь, что ваш форк содержит актуальные изменения из основной ветки оригинального репозитория. Подробнее об этом написано в разделе ниже.

На сайте **[tokamak.mephi.ru/git](https://tokamak.mephi.ru/git/mephist0/MephistDataKit)** на странице репозитория нажать кнопку "Запрос на слияние" (над поисковой строкой правее надписи ветки main и левее кнопки "Найти файл")

Выбрать свой форк для "взять из". Создать запрос.

### 5. Рекомендуется уведомить мейнтейнеров о наличии запроса на слияние

# Синхронизация форка с оригинальным репозиторием

### 1. Предполагается, что:

* У вас уже есть локальная копия вашего форка (выполнен git clone ...).

* Вы знаете URL оригинального репозитория (например, https://tokamak.mephi.ru/git/mephist0/MephistDataKit.git).

### 2. В терминале перейдите в рабочую директорию вашего репозитория

### 3. Добавьте оригинальный репозиторий как удалённый (upstream)

Для этого выполните команду

`git remote add upstream https://tokamak.mephi.ru/git/mephist0/MephistDataKit.git`

Если вы уже добавляли upstream раньше, этот шаг можно пропустить.

### 4. Убедитесь, что у вас есть все ветки из upstream

Для этого выполните команду


`git fetch upstream`

### 5. Переключитесь на ту ветку, которую хотите обновить

Скорее всего это ветка main

`git checkout main`

### 6. Слейте изменения из upstream в вашу локальную ветку

Есть два основных подхода: слияние (merge) или перебазирование (rebase). Для новичков проще использовать merge:

`git merge upstream/main`

Если вы хотите, чтобы история оставалась линейной (рекомендуется), можно использовать rebase:

`git rebase upstream/main`

При возникновении конфликтов их нужно разрешить вручную. После разрешения конфликтов при merge потребуется сделать коммит слияния, а при rebase — продолжить `git rebase --continue`.

### 7. Отправьте обновлённую ветку в свой форк на сервере

`git push`

Теперь ваш форк на сервере содержит все актуальные изменения из оригинального репозитория.

# Синхронизация форка через веб-интерфейс

Посмотрите на странице вашего форка — при его отставании на сайте **[tokamak.mephi.ru/git](https://tokamak.mephi.ru/git/mephist0/MephistDataKit)** на странице форка  появится кнопка "Синхронизировать". В простейшем случае при ее нажатии сервер сам подтянет изменения из оригинального репозитория в ваш форк. Вам останется только выполнить команду `git pull` на рабочем компьютере перед внесением изменений.
